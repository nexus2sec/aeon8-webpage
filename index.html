Who We Are

Aeon8 Systems — Company Overview

Aeon8 Systems is a deep-tech cybersecurity company based in Gurugram, Haryana, India. We sit at the intersection of kernel engineering, applied machine learning, and sovereign infrastructure — building tools that work in environments where foreign SaaS is simply not an option.

We operate two arms: a product engineering team building Aeon Sentinel (an eBPF/XDP-native network enforcement platform) and an education institute, Aeon8 Academy, delivering hands-on cybersecurity and software training from Gurugram.

Our engineering philosophy is Rust-first for performance-critical paths, Python + ONNX for ML inference, and fully open-core (GPL-3.0). Every product we ship must run completely offline — zero cloud dependency is a hard requirement, not a feature toggle.

Mission: Secure. Empower. Sovereign.

Our Field

What We Work In

Aeon8 operates at the deepest layer of the security stack — kernel, network, and intelligence.

01

Kernel & eBPF/XDP Engineering

We write eBPF programs that execute inside the Linux kernel at NIC receive time. XDP drops, rate-limits, and reroutes packets before they ever reach user space — the fastest possible enforcement path.

02

Network Security & Threat Intelligence

Network forensics, PCAP analysis, TLS fingerprinting (JA3/JA3S), MISP/IOC integration, and swarm-distributed ban propagation over QUIC. Built for SOC analysts and network defenders.

03

Applied ML for Threat Detection

22-feature RandomForest anomaly detection using ONNX Runtime — runs fully offline. No external API calls. Behavior drift, port scan, and DDoS pattern detection tuned for production packet paths.

04

ICS/SCADA & OT Security

Operational Technology security for power grids, industrial control systems, and nuclear-adjacent infrastructure. Air-gap native, CERT-In aligned, designed for environments that cannot tolerate downtime.

05

Cybersecurity Education & Training

Hands-on security training from fundamentals to kernel-level specialization. Red Team, SOC, Network Forensics, ML Detection — all with live labs, not slides. Global cert preparation included.

06

Sovereign Software Development

Full-stack web, AI/ML applications, game development, and secure coding — designed for developers who will work in or alongside India's digital infrastructure. Privacy-first, OWASP-hardened.

Engineering Philosophy

How We Build

Performance-critical paths in Rust. Intelligence in Python. Interfaces in React/Next.js. Data in PostgreSQL. Everything runs offline-first.

🦀

Rust + PyO3

Detection engine, P2P gossip, and XDP policy evaluation. Memory-safe, zero-overhead FFI to Python ML layer.

🛠

eBPF / XDP

Linux kernel programs compiled with LLVM. NIC-level packet processing, policy hooks, and real-time enforcement without syscall overhead.

🤖

Python + ONNX

ML pipeline: feature extraction, RandomForest training, scikit-learn → ONNX export. Runtime inference at <1ms per packet burst.

🌐

React / Next.js

Web interfaces, admin panels, and the Sentinel management dashboard. TypeScript, server components, Edge-ready.

💾

PostgreSQL

Primary data store for events, threat logs, and audit trails. Full-text search, JSONB for flexible event schemas.

📤

QUIC / P2P Mesh

Swarm-wide ban propagation. Decentralized gossip protocol — no central choke point, sub-millisecond sync across nodes.

🔒

Air-Gap First

Every component ships with offline mode as the default. MISP/CSV intel feeds, local ONNX inference, no external API required.

🤝

Open Core GPL-3.0

Core Sentinel is fully open source. Commercial support, extended enterprise features, and custom deployment available.

Development Approach

How a Feature Goes from Idea to Production

Threat Modeling

Every feature starts with a threat model. STRIDE analysis, attack surface review, OWASP alignment before a single line of code.

Kernel + Rust Core

Performance path written in Rust with eBPF. Benchmarked against Suricata/Snort. Must achieve <1µs at target load before merge.

ML Pipeline

Feature engineering in Python → scikit-learn training → ONNX export → offline runtime validation on MAWI dataset traffic.

Ship & Monitor

Docker + systemd packaging. Air-gap offline installer. Prometheus/Grafana metrics. CERT-In compliance scan. GPL-3.0 release.
